# 已确认的产品决策

以下内容来自需求核对，后续实现以此为准。

## 内容与迁移

- 首版迁移所有真实经验帖，人工去重，排除 `Test-User`、`TestUser` 等测试稿。
- 历史经验帖正文原样保留，不润色、不改写、不删减。
- 允许在正文上方增加或调整 YAML 文件头，用于年份、作者、封面和发布状态等结构化信息。
- 学校信息只保留在正文，不新增 `appliedSchools` 字段。
- 夏令营/预推免信息只保留在正文，不新增 `stages` 字段。
- 不保留通用 `tags` 字段，首版不做学校、阶段或标签筛选。
- 历史文章已有的图片和附件全部迁移，并和对应作者的文章放在同一目录。
- 附件逐项审核，确认可公开后才进入项目仓库。
- 尽量兼容旧网站文章链接。
- 新版 GitHub 仓库只包含 `project/`，本地 `references/` 仅用于前期参考，不进入项目仓库或生产构建。

## 站点结构

- 对外名称：`JNU CS BAOYAN`。
- 主导航：主页、经验贴、保研流程、资料与工具、投稿、关于。
- 经验贴按申请年份组织，详情地址采用 `/experiences/<year>/<stable-id>/`。
- 列表和首页按申请年份倒序，同一年按发布时间倒序。
- 首版不提供全文搜索，后续再增加静态搜索。
- 首页顶部保留“最前面的话”，作为独立 Markdown 页面维护，并配一张单独的项目介绍图片。
- “最前面的话”先沿用旧 README 开场文字，只把旧邮箱替换为 `eeecank@163.com`；旧“保研服务”段落首版保留，后续由维护者手动修改。
- 保研流程保留原时间线节点，作为流程说明，不作为经验贴分类。
- 资料与工具保留六类：工具推荐、简历与个人陈述、专业课、机试、英语、数学。
- 关于页保留贡献者致谢，移除旧邮箱、QQ 和旧服务联系方式。
- 投稿页公开 `eeecank@163.com`，同时用于投稿、更正、撤下和内容反馈。

## 投稿模板

- 提供 Markdown 和 Word 两种模板。
- 模板正文结构：标题、个人背景、申请经历、各院校参与情况、最终去向、复盘与建议。
- 作者可使用真实姓名、昵称或匿名。
- `applicationYear` 对新投稿必填；历史文章缺失时由维护者补齐，无法确认的标记为待整理。
- 投稿者只填写普通 Markdown，管理员发布前统一补 YAML。
- 投稿者不必提供图片；提供时作为封面，没有图片则由维护者选择统一的全站默认封面。
- 新投稿默认一份 Markdown 加一张可选封面图；历史文章的多图和附件按原状保留。

## 视觉与技术

- 使用 Astro 官方 Blog Starter 作为项目骨架。
- 使用 Astro Content Collections、TypeScript、原生 CSS 和静态输出。
- 采用米白、炭灰、陶土橙配色，只做浅色模式。
- GitHub Pages 采用项目站点形式：`https://<username>.github.io/<repo>/`。
- 具体 GitHub owner/name 由维护者后续提供，暂不写死部署配置。
